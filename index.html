ตั้งค่า Google Apps Script Web App

นำลิงก์ Web App URL ที่ได้จากการ Deploy Google Apps Script มาใส่ที่นี่ ระบบจะบันทึกจำไว้ในบราวเซอร์นี้

แนะนำวิธีใช้งาน:

  1. เปิดไฟล์ google_apps_script.js นำโค้ดไปวางใน Google Apps Script
  2. กดปุ่ม Deploy > New deployment เลือกประเภท Web app
  3. ตั้งค่า Execute as: Me และ Who has access: Anyone
  4. คัดลอก Web app URL ที่ได้มาใส่ในช่องด้านบน
